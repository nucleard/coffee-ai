The query system

A question-answering system over everything a roastery knows about its coffee: Cropster roast data, Shopify orders, green quality readings (moisture, water activity, roast colour), cupping notes, customer records, meeting notes. Anyone on the team asks from their phone and gets an answer that quotes the source.

When a roastery's production grows thirty times in five years, its information ends up spread across more systems than one person can keep track of. The person on the floor at four o'clock needs to find one fact quickly, and this system gives the whole team one place to ask.

The demo vault holds invented coffees, customers and numbers. The real one is in use by one roastery's team and stays private.

How answers are kept to the records

Source
The system answers only from the vault, which is around five hundred markdown files, some written by hand and some synced by machine.
Models
A small model turns the question into a fetch plan and plain Python runs the plan. A second model writes the answer from the fetched records and names the file each part came from. The second model is given only those records, so it has no other source to cite.
Numbers
Python does the arithmetic for revenue, kilos and top customers from the order ledgers. The model puts the result into words, and the answer says what was excluded.
Shared files
Sync jobs and people write to the same documents. A sync job rewrites only its own marked section of a customer note and leaves my notes around it untouched.
Voice
You can dictate in Spanish, French, Dutch or English. The pipeline works in English and translates the question and the answer.

The system has been live for the team since August 2026. The front end is a phone-sized web page. Most of the work is in the back end, which consists of the sync jobs, the fetch planner, the ledger parsers and the vault.

The system contains nothing specific to coffee, so it could be set up in the same way for a winery's cellar records, a restaurant's suppliers and bookings, or a label's samples and orders.
